# Sensor board — PCB layout (placement pass, 2026-07-30)

`sensor.kicad_pcb`, generated by `gen/pcb_build.py` from `sensor.kicad_sch`
(same generated-not-hand-edited rule as the schematic and as the main board:
edit the script, re-run, never hand-edit the `.kicad_pcb`). Runs on KiCad's
`pcbnew` Python API under KiCad's own interpreter:

```
cd gen
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3.9 pcb_build.py   # build + QA report
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3.9 pcb_check.py   # independent re-check of the saved file
/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli pcb drc --severity-all ../sensor.kicad_pcb
```

**Scope: placement + outline + mounting + stackup + GND pours + thermal
keepout + full net assignment + silkscreen. No traces are routed** — same
convention as the main board (`../kicad/PCB_NOTES.md`). The ratsnest is
complete and net-correct, ready for interactive routing; the placement was
chosen so that routing is short and dull (see *Routability* below).

## Board

| | |
|---|---|
| Size | **30 × 16 mm** (4.8 cm²), rounded corners r = 1 mm |
| Stack | **2 layers**, 1.6 mm FR4, 1 oz. GND pour on both sides (filled) |
| Rules | clearance **0.22 mm**, track 0.25, via 0.6/0.3, min drill 0.3, copper→edge 0.5 |
| Mounting | 2 × **M2 NPTH** (Ø2.2), opposite corners, 25.3 mm apart |
| Assembly | double-sided SMT reflow (PCBA) — no hand soldering, see README §Assembly |

Two layers, not four: the only fast signal is 400 kHz I²C, and a *split*
ground would work against the one thermal requirement this board has (below).
1.6 mm rather than 0.8/1.0 for stiffness — the IMU has to read the enclosure's
gravity vector, not board flex.

## The six requirements → what was built

| # | Requirement | Result |
|---|---|---|
| 1 | Part clearance ≥ 0.22 mm | **0 violations.** Tightest pair 0.25 mm (H1↔TP2, TP1↔TP2); 14 pairs in the 0.25–0.30 "tight" band, everything else looser. The **copper clearance rule is set to 0.22 mm too**, so the requirement holds in both senses; every footprint here can hold it (tightest in-footprint pad gap is 0.25 mm, on U1 and U3) |
| 2 | 2 mounting holes | H1 (3.1, 3.1) and H2 (26.5, 12.6), M2 Ø2.2 **non-plated** |
| 3 | Light + ambient sensors on the front | **F.Cu = U3 (TSL2591) + U2 (BME688) and nothing but their own local passives** (C10/C11/R10/R11 for U2, C12/R12 for U3) — 8 parts |
| 4 | J1 on the back | J1 (JST ZH B6B-ZR, vertical) on B.Cu at the right end, cable exits straight off the back into the cube |
| 5 | No interference between the sensors | see *Sensing* below |
| 6 | Small | 30 × 16 mm. The back is the constrained side (23 parts incl. the 11.6 × 4.6 mm connector courtyard); the front deliberately stays sparse so the two apertures are clean |

## Sensing — why each sensor sits where it sits

**U2 · BME688 (gas/VOC + RH + T) — bottom-left corner, front.**
The gas sensor is the only part on this board with a placement problem, so it
got the corner and everything else was placed around it:

- **9.1 mm from U1** (3.6 mm of courtyard gap). U1 is the only self-heating
  part on the board (~35 mW); the BME688's own heater is compensated by BSEC,
  a neighbour's warmth is not.
- **23 mm from J1** — as far as the board allows from the **PVC harness**.
  Plasticiser outgassing off PVC insulation is a genuine VOC-baseline
  offender, and it is the one contaminant this design actually invites (a
  200 mm cable ending 2 cm from a gas sensor).
- **Copper-pour keepout** (`U2_thermal_island`, 1.6, 8.2 → 7.6, 13.4 mm, both
  layers) breaks the ground plane around it, per the Bosch BME680/688 design
  handbook's "reduce the copper area around the sensor" — board heat now has
  to cross FR4, not 35 µm of copper, to reach it. The five signals still
  reach the part on tracks; only the pour is excluded.
- **Nothing on the back behind it** (verified by `pcb_check.py`), so the
  enclosure vent can be a plain hole and air reaches both faces.
- Its own two 100 nF (C10/C11) sit 1.9/2.0 mm away on the supply-pin edge,
  and the address strap R10/R11 on the SDO edge — nothing crosses the vent.

**U3 · TSL2591 (ambient light) — top edge, front, 10.3 mm from U2.**
- ≥ 0.64 mm of clear courtyard all round and the only neighbours (C12, R12)
  are 0.5 mm-tall 0603s — nothing shadows a window above the part.
- Far from J1's through-hole pads, which poke through to the front side.
- Separate from the vent, so the enclosure gets **one clear window and one
  mesh/vent**, not one shared hole (a vent has to be open; an ALS window
  should not be).
- C12 (1 µF low-ESR) is 1.8 mm from VDD — the one hard placement rule the
  TSL2591 datasheet gives.

**U1 · BNO085 (9-DOF) — centre, back, with the connector.**
Putting the IMU on the connector side is the trade the brief allowed, and it
pays for itself three times: it clears the whole front face for the two
apertures, it puts the IMU **on the line between the two screws** (1.2 mm off
it, 25.3 mm span) where the board is stiffest — an IMU on a flexing corner
reads its own board — and it keeps the 32 kHz crystal loop tiny.
- **Y1 2.4 mm from XIN32/XOUT32**, directly below the part, with C7/C8
  flanking it and no crossover (Y1.1 → pin 26, Y1.2 → pin 27, in that
  order). This is the one net on the board that deserves the prime real
  estate: high-impedance, 12.5 pF CL, ±20 ppm.
- Supply decoupling (C3/C4 100 nF, C5 1 µF) on the **opposite side from the
  digital pins**, 1.7–2.3 mm from VDD/VDDIO.
- Host side (SCL/SDA/H_INTN/SA0/CSN/ENV) faces J1; CAP + the 10 k/100 nF
  power-on reset sit above; the two DFU test pads (TP1 NRST, TP2 BOOTN) are
  on the back, reachable with a probe while the board is out of the case.
- **Magnetometer note: use nylon or brass M2 hardware.** A steel screw 8 mm
  from a magnetometer is a permanent hard-iron offset. The holes are NPTH
  for the same family of reasons (below).

**Why the mounting holes are non-plated.** The main board is bolted to the
aluminium front plate; if this board's ground plane were bolted to the same
metal, the harness's single GND wire plus the chassis would form a loop
around the whole clock, and every return current in it would cross this
board's plane under the I²C and the ALS. Isolated holes keep the sensor
board's ground single-point — it comes in on J1 pin 1 and leaves nowhere.

## Routability (placement was judged on it, but nothing is routed)

- **U1's LGA-28 is a single perimeter ring** — every pad escapes *outward*,
  so nothing has to squeeze between two 0.5 mm-pitch pads and the 0.22 mm
  clearance rule is achievable with a 0.2 mm trace. Its four sides face the
  four things they talk to: supplies left, crystal down, host right, reset up.
- Front side carries 8 parts on 4.8 cm² — the **F.Cu pour is essentially
  solid under U1** (341 mm² filled), giving the IMU the reference plane CEVA
  asks for even on a 2-layer board.
- I²C runs one straight trunk: J1 (pins 3/4) → R1/R2 → U1's right column →
  two vias → U2 and U3 on the front. No stubs longer than ~3 mm.
- `GND` is the pour on both sides with **solid (not thermal-relief) pad
  connections** — this board is reflowed, never hand-soldered, so relief
  spokes would only add impedance, and several GND pads sit in channels the
  pour can reach from one side only (a 2-spoke thermal rule would starve them
  forever).
- Estimated total ratsnest (per-net MST): **253 mm** for 31 parts.

## Verification (all reproduced by re-running the two scripts)

- `pcb_build.py`: **0 courtyard errors** (floor 0.22 mm), **0 edge
  violations**, **0 missed pad→net lookups**, all 5 requirement assertions
  OK. A `VERIFY_PINS` table asserts 14 critical pad world-positions every
  build, so a footprint-transform regression cannot slip through (it caught
  two during this layout: back-side `rot 180` mirrors **Y**, and back-side
  `rot 90` is `(ax−ly, ay+lx)`).
- `pcb_check.py` (independent — loads the saved file, re-exports the netlist,
  re-derives the outline from Edge.Cuts): **16/16 checks pass**, including
  all 100 schematic pins matched to a pad carrying the right net, no netless
  copper pad, and the thermal island enclosing U2.
- `kicad-cli pcb drc --severity-all`: **0 clearance, 0 shorts, 0 drill, 0
  courtyard, 0 starved-thermal**; 3 silkscreen-clearance warnings (all
  label-vs-label or label-vs-part-outline, none over a pad — the placer
  hides a reference rather than print silk onto a solder pad; only C11's is
  hidden, and it still reads on F.Fab); 62 unconnected items = the ratsnest.
- `kicad-cli sch erc`: still **0 violations** — the PCB build restores the
  eeschema-only keys that `board.Save()` strips out of `sensor.kicad_pro`.
- Rebuild is **semantically identical** (same positions, rotations, sides,
  pad nets, edge cuts, texts, zones); the file is not byte-identical because
  pcbnew mints fresh UUIDs each save.

## Fixed while laying this out

- **`sensor.pretty/CEVA_BNO085…` 3D model**: the SnapEDA STEP is authored
  Y-up, so with `(rotate 0 0 0)` the body lay in the board plane and stuck

## 3D models (2026-08-02)

All 29 real parts resolve a model file (the four without one are the two M2
mounting holes and the two test pads — nothing to draw), and
`kicad-cli pcb export step` loads every one: the assembly measures
**Z −4.585 … +2.615**, i.e. J1's wafer stands 4.5 mm off the back and its pins
clear the front by 0.93 mm.

Two footprints pointed at models that are **not in the KiCad 10 install**, so
they rendered as bare pads:

| Ref | Stock model referenced | Now |
|---|---|---|
| U3 TSL2591 | `OptoDevice.3dshapes/DFN-6_2x2.4mm_P0.65mm.step` (absent) | ams `SON-06-FN` package STEP as `3d/AMS_TSL25911FN.step`, offset/rotate 0 — it is authored on the seating plane with the pin-1 dot over the −x/+y pad, which is this footprint's pad 1 |
| J1 JST ZH | `Connector_JST.3dshapes/JST_ZH_B6B-ZR_…step` (the library has no ZH models at all) | `3d/JST_ZH_B6B-ZR_1x06_P1.50mm_Vertical.step`, generated by `../kicad/gen/mk3d.py` from `datasheet/connector_jst_zh.pdf` |

Both are wired up through the shared `../kicad/gen/models3d.py` `OVERRIDES`
table, which the main board's `add_footprint()` (this project reuses it)
applies on every rebuild. To patch them into an already-laid-out board without
regenerating it:

```
python3 ../kicad/gen/models3d.py sensor.kicad_pcb
```

⚠ J1 is `B6B-ZR`, the 2.7 mm-tail variant; JST specifies that tail for
0.6–1.2 mm boards and `B6B-ZR-3.4` for 1.6 mm. Footprint-compatible, BOM-line
change only — see the main board's notes, whose J7 is the same part.
